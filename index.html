Sélectionnez votre filière dans le menu de gauche pour accéder à vos ressources.

Guide d'utilisation rapide
1

Choisissez votre année

Utilisez les boutons "1ère année" / "2ème année" en haut du menu pour filtrer les filières correspondantes.

2

Sélectionnez votre filière

Cliquez sur votre filière (MPSI, PCSI, TSI, MP, PSI) pour accéder à toutes les matières disponibles.

3

Naviguez dans les matières

Choisissez une matière (Maths, Physique, Chimie, SI, Info) puis le type de ressource souhaité.

4

Ouvrez vos PDF

Cliquez sur "Ouvrir" ou "Correction" pour accéder directement au fichier sur Google Drive.

💡 Pour l'administrateur : Cliquez sur "Panneau administrateur" en bas du menu pour ajouter vos cours, exercices, devoirs et livres depuis Google Drive.

✓ Concours ajouté !
1

Préparez vos fichiers sur Google Drive

Organisez vos PDFs dans des dossiers Google Drive (ex: "MPSI/Maths/Exercices/S1").

2

Rendez les fichiers publics

Clic droit sur le fichier → Partager → Changer pour "Tout le monde avec le lien" → Copier le lien.

3

Collez le lien dans le formulaire

Remplissez le formulaire correspondant (exercice, devoir, livre ou concours) et collez le lien Google Drive.

4

Hébergez sur GitHub Pages (gratuit)

1. Créez un compte sur github.com
2. Nouveau repository public → uploadez ce fichier HTML
3. Settings → Pages → Branch: main → Save
4. Votre site : votrenom.github.io/prepa

⚠️ Important : Les données sont sauvegardées dans le navigateur (localStorage). Pour les partager avec les élèves sur GitHub Pages, exportez et ré-importez les données ou utilisez un service de base de données en ligne comme Firebase.
